# CONVERGE 2026 — Conference Schedule

> **Where ideas become what’s next.**

A premium, accessible, and responsive single-page conference schedule web application for **CONVERGE 2026**, a two-day technical engineering summit in **Bengaluru, India — October 14–15, 2026**.

The experience is designed around a high-end editorial dark aesthetic with interactive scheduling, parallel conference tracks, session details, search, bookmarking, calendar exports, keyboard navigation, and WCAG 2.2 AA accessibility.

## 📸 Overview

CONVERGE 2026 brings together engineers, researchers, systems architects, and creators exploring the future of:

- 🤖 Artificial Intelligence
- ⛓️ Web3 & Cloud Infrastructure
- 🦾 Autonomous Robotics
- ⚡ Emerging Technologies

The application acts as an interactive conference program guide, helping attendees discover sessions, compare parallel tracks, build a personalized schedule, and access detailed speaker information.

## ✨ Features

### 📅 Two-Day Conference Schedule

Switch seamlessly between:

- **Day 1 — Wednesday, October 14, 2026**
- **Day 2 — Thursday, October 15, 2026**

The day selector uses keyboard-navigable WAI-ARIA tabs for an accessible experience.

## 🔎 Live Search & Filtering

Search conference sessions instantly by:

- Session title
- Speaker name
- Company
- Track
- Topic
- Experience level

Search results update dynamically with an accessible result-count announcement.

---

## 🔖 Personal Schedule

Users can bookmark sessions and create their own personalized conference schedule.

Bookmarks are persisted using browser storage, allowing saved sessions to remain available across browser sessions.

---

## 🧑‍💻 Session Details

Each session opens inside an accessible modal dialog containing:

- Session title
- Speaker
- Speaker role
- Company
- Biography
- Key takeaways
- Topic tags
- Track
- Session duration
- Experience level
- Bookmark action
- Calendar export
- Shareable session URL

---

## 📆 Calendar Integration

Sessions can be exported as `.ics` calendar invitations.

This allows attendees to add individual sessions directly to their preferred calendar application.
